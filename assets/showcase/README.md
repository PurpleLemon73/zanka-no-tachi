# Original showcase assets

Ashen Blade and Nova Pulse are fictional titles created solely to demonstrate
Zanka no Tachi without retaining or publishing third-party validation media.

The raster artwork in this directory was generated for this project with
OpenAI's image-generation tool, then selected and integrated as deterministic
offline sample media. It depicts original characters, settings, symbols, and
lore. These titles are not real provider entries.

- `ashen_blade/`: vertical cover and three manga-style pages
- `nova_pulse/`: vertical poster, 16:9 hero, and two cinematic stills

Do not replace these files with provider screenshots or copyrighted pages/video
frames when updating public screenshots.
