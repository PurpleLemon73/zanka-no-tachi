# Zanka no Tachi v0.2.0-beta.2 — Production-Signed Beta

This release establishes Zanka's permanent Android signing identity and
modernizes the supported Android build stack. It contains no `media_kit`
experiment; production playback remains `video_player`.

## Required beta.1 migration

Beta.1 was debug-signed, so Android cannot update it in place. Back up beta.1,
save the backup outside app storage, uninstall beta.1, install beta.2, then
restore. See [the complete migration guide](BETA1_TO_BETA2_MIGRATION.md).

Future production releases should update beta.2 normally when signed by the
same permanent identity.

## Signing

Expected signer SHA-256:
`3F:4A:86:F7:F4:DD:A3:98:E0:4D:D0:59:DD:33:D7:FC:27:4C:AC:B3:62:17:A4:68:B6:D8:D7:C7:07:4C:13:41`

The published APK and checksum values are filled from the verified release
pipeline output. Physical Fire TV validation remains deferred and this release
does not claim Fire TV certification.
