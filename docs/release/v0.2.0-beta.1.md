# Zanka no Tachi v0.2.0-beta.1 — First Public Beta

The first public beta brings one adaptive Android APK to phones, tablets,
Android TV, Google TV, and Fire TV-compatible devices.

## Highlights

- Canonical, multi-source manga and anime library
- MangaWorld live manga reading where public chapter media is verified
- AnimeWorld live playback for observed public direct MP4/HLS delivery
- Lawful local folder/CBZ reader and local-video player
- Smart Start / Resume / Next / Completed actions
- Canonical completion plus exact source-specific page/timestamp resume
- Paged manga zoom/pan, read/unread, watched/unwatched, and autoplay
- Local import, repair, storage maintenance, and portable data-only backup
- Material 3 themes and persisted accent color
- D-pad TV Home/Search/Library/Details and remote-first player controls

## Validation status

Android phone behavior was physically smoke-tested on a Samsung SM-S948B
running Android 16. Android/Google TV behavior retains the complete M14 Google
TV API 36 validation. M15 also installed the beta APK through its Leanback entry
on an Android TV API 36 ARM64 `Television 4K` AVD and rendered the TV Home at
3840×2160 with deterministic focus. M15's safe showcase was separately rendered
on physical Android using the same TV presentation. No physical Fire TV was
available, so Fire OS support is architecture-compatible but not physically
certified.

## Artifact and signing

`zanka-no-tachi-v0.2.0-beta.1.apk`

The prepared beta artifact is a **debug-signed development APK**, not a
production-signed store artifact. Its SHA-256 checksum must be published beside
the download. Production release signing remains maintainer-owned; the project
does not contain keys and never falls back to debug signing for release builds.

## Known limitations

- Live providers can change markup or delivery at any time; unsupported
  installments remain metadata-only.
- No protected-content extraction, authentication/CAPTCHA/anti-bot bypass, DRM
  circumvention, or automatic alternate-domain discovery.
- No cloud sync, background playback, TV home recommendations/channels, or
  TV-specific manga-reader redesign.
- Fire TV runtime validation and production release signing remain outstanding.

All screenshots and showcase media use the original fictional Ashen Blade and
Nova Pulse assets created specifically for Zanka. Zanka is independent and
unofficial and grants no rights to third-party content.
