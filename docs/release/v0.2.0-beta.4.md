# Zanka no Tachi v0.2.0-beta.4 — Reader UI v2

Beta.4 brings chapter navigation directly into the manga reader and adds
user-controlled video fit and aspect-ratio presentation while preserving
canonical completion and exact source-specific resume.

## Manga Reader UI v2

- Previous Chapter and Next Chapter are available inside the reader at truthful
  canonical boundaries.
- Completing a chapter presents a prominent Next Chapter action and an honest
  end-of-available-content state.
- The canonical chapter picker renders lazily, identifies current/completed
  state, and remains bounded for very large manga.
- Volume controls appear only when genuine canonical or user-edited volume
  metadata exists.
- Manual Next starts at page one without deleting or consuming an exact resume
  saved for the destination source binding.

## Video Display Mode

Fit and aspect ratio are independent controls. Auto / Original preserves the
decoder-reported intrinsic ratio and remains the safe default. Fit, Fill / Crop,
Fit Width, Fit Height, and explicit Stretch / Fit Parent are available alongside
Original, 4:3, 16:9, 16:10, 21:9, 1:1, 3:2, and 5:4 presets. Positive custom
ratios such as `2.39:1` are supported. Changes apply to the existing playback
session live: they do not reopen playback, seek, or mutate canonical/source
progress.

## Production playback and upgrade continuity

`video_player` remains the sole production playback engine. No experimental
player runtime or probe fixture is packaged. Beta.2 through beta.4 use the same
permanent production signing identity, so beta.3 updates normally to beta.4 in
place. Beta.1 was debug-signed and still requires the documented backup →
uninstall → install → restore migration.

## Known limitations

- Advanced selectable embedded audio/subtitle tracks remain unavailable with
  the production player.
- Physical Fire TV validation remains pending; this is not Fire certification.
- Vega OS is unsupported.
- The unchanged M13 physical zoom evidence remains valid; M18 adds automated
  widget regression coverage for zoom reset across chapter transitions.
