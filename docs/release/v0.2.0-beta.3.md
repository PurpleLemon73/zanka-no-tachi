# Zanka no Tachi v0.2.0-beta.3 — Player UI v2

Beta.3 makes anime playback easier to use on both touch and TV devices while
keeping canonical identity, completion, and exact source-specific resume intact.

## Highlights

- Player UI v2 with Previous Episode, Next Episode, Replay, a prominent Next
  Episode completion action, and a truthful end-of-available-content state.
- A lazy in-player canonical episode picker, timeline scrubbing, current/total
  time, and ±10-second seeking.
- D-pad-first TV control behavior and mobile touch adaptation.
- A plugin-neutral playback-engine boundary behind the product UI.

## Production playback and safety

`video_player` is the sole production engine. The experimental `media_kit`
runtime, probe, fixtures, and generated registrations were rejected after its
M17 Television_4K reliability, integration, package-size, and LGPL-compliance
gates did not pass. They are absent from this release artifact.

## Upgrade continuity

Beta.2 and beta.3 use the same permanent production signing identity, so beta.2
updates normally to beta.3 in place. Beta.1 was debug-signed and still requires
the documented backup → uninstall → install → restore migration.

## Known limitations

- The production engine does not currently expose advanced selectable embedded
  audio/subtitle tracks or external subtitle loading.
- Physical Fire TV validation remains pending; this is not Fire certification.
- Vega OS is unsupported.
